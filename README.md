# Monty Hall Problem Simulator

![Monty Hall Problem](https://thumb.wikimedia.org/wikipedia/commons/thumb/3/3f/Monty_open_door.svg/1280px-Monty_open_door.svg.png?utm_source=en.wikipedia.org&utm_campaign=index&utm_content=thumbnail)

A small `JavaScript` script that simulates many rounds of the Monty Hall Game scenarios with player not switching the door, and with player switching the door.

While there are 3 doors, switching yields better chances to win (1/3 against 2/3). However, as the amount of doors increase, the difference decreases significantly. Regardless, switching is a better choice as seen in the simulation.

[Learn more about the Monty Hall Problem](https://en.wikipedia.org/wiki/Monty_Hall_problem)
